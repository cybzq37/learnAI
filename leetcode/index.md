

## Day 1：建立套路地图

### 数组 + 哈希 + 双指针

重点题：

* 两数之和
* 字母异位词分组
* 最长连续序列
* 移动零
* 盛最多水的容器
* 三数之和

掌握：

```text
HashMap / HashSet
双指针
排序 + 双指针
```

> `HashMap / HashSet`：遇到“查找某个数是否出现过”“统计频率”“寻找配对”先想到它。

### 滑动窗口 + 前缀和 + 二分

重点：

* 无重复字符的最长子串
* 找到字符串中所有字母异位词
* 和为 K 的子数组
* 搜索旋转排序数组
* 在排序数组中查找元素

重点形成两个条件反射：

```text
连续区间 + 最长/最短
→ 滑动窗口
```

```text
连续子数组 + 和/次数
→ 前缀和 + HashMap
```
> **连续子串 / 连续子数组 + 最长/最短/满足条件** 第一反应应该是**滑动窗口**。

### 链表

建议重点吃透：

* 反转链表
* 合并两个有序链表
* 环形链表
* 删除链表的倒数第 N 个结点

```text
dummy node

```

> **快慢指针 + 虚拟头节点 + 链表反转** 

这三个模板一定要会。


### 二叉树

重点：

* 二叉树的最大深度
* 翻转二叉树
* 对称二叉树
* 二叉树的层序遍历
* 二叉树的直径
* 二叉树的最近公共祖先
* 二叉搜索树的相关题

把所有题归到：

```text
DFS
├── 前序
├── 中序
└── 后序

BFS
└──  队列 + 层序遍历
```

你不应该记“这道题的代码”，而应该记：

> **递归函数到底返回什么？**

### 栈 + 单调栈 + 堆

重点：

* 有效的括号
* 最小栈
* 每日温度
* 柱状图中最大的矩形
* 数组中的第 K 个最大元素
* 合并 K 个升序链表

重点识别：

```text
括号匹配 → Stack

下一个更大/更小
→ Monotonic Stack

Top K
→ Heap
```

> **“下一个更大/更小元素” → 单调栈。**

例如每日温度，看到“未来哪一天温度更高”，就应该想到单调栈，而不是暴力往后找。

### 回溯

重点：

* 全排列
* 子集
* 电话号码的字母组合
* 组合总和

你只需要真正理解一个模板：

```text
def backtrack(path, choices):
    if 满足结束条件:
        ans.append(path)
        return

    for choice in choices:
        做选择
        backtrack(...)
        撤销选择
```

然后理解：

> **回溯 = DFS + 撤销选择。**

### 一维 DP

* 爬楼梯
* 打家劫舍

* 零钱兑换

### 二维 DP

* 不同路径
* 最长公共子序列
* 编辑距离

### 序列 DP

* 最长递增子序列

你只需要牢牢记住：

```text
1. dp[i] / dp[i][j] 是什么？
2. 最后一步是什么？
3. 状态转移是什么？
4. 初始值是什么？
5. 遍历顺序是什么？
```

不要在两天突击的时候钻特别难的 DP。
