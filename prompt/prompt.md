# 如何设计一个好的prompt？

好的Prompt = 角色 + 任务 + 背景 + 输入 + 要求 + 输出格式 + 约束 + 示例

> 1. 一定要定义角色，llm本质还是按照概率输出，设置一个角色，能够使范围收敛。  
> 2. 任务一定要具体。  
> 3. 给AI足够的背景，这样llm不会因为缺少上下文而给出泛泛的答案。一个好的原则是，凡是你觉得AI应该知道的，其实它都不知道。  
> 4. 明确成功标准，尽量量化。  
> 5. 给出具体的输出格式，如果是表格，给出表头信息等。  
> 6. 加上边界条件，AI的回答很容易越界。  
> 7. 给出示例。  

一个非常好用的高级技巧：让 AI 先检查问题。对于复杂任务，可以加：

> 在开始回答之前，请先检查我的要求是否存在歧义、缺少关键信息或互相冲突。如果存在，请先指出；如果信息已经足够，则直接执行。

下面是一个 prompt 的模板：

```text
# 角色

你是一名【专业角色】，擅长【相关能力】。

# 任务

请帮我完成【具体任务】。

# 背景

我的情况是：

* 【背景信息 1】
* 【背景信息 2】
* 【目标】
* 【已有资源/限制】

# 输入

以下是你需要使用的信息：
【粘贴资料/数据/文本】

# 要求

请遵循以下要求：

1. 【要求 1】
2. 【要求 2】
3. 【要求 3】
4. 【限制条件】

# 输出格式

请按照以下结构输出：

1. 【第一部分】
2. 【第二部分】
3. 【第三部分】

# 质量标准

一个好的结果应该：

* 【标准 1】
* 【标准 2】
* 【标准 3】

如果信息不足或存在歧义，请先指出，不要自行编造。
```
如果任务很复杂，可以分阶段prompt。

判断一个 prompt 好不好的方法，写完以后问自己 5 个问题：

> 1. AI 知道我要它做什么吗？
> 2. AI 知道为什么要做吗？
> 3. AI 知道我的具体情况吗？
> 4. AI 知道什么样的结果才算好的吗？
> 5. AI 知道最终应该怎么输出吗？
